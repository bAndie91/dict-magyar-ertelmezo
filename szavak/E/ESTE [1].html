ESTE [1] [e-e] határozószó és főnév, (népies, régies) estve
  • I. határozószó A napnak abban a szakaszában, amikor már sötétedik, főleg naplemente után, de még éjjel előtt. Egy este: valamikor az esti időben; minden este; tegnap, ma, holnap, másnap este; este abbahagyjuk a munkát. Csak este szokott otthon lenni. Késő este; este nyolckor. Este korán lefeküdt. □ Estve jött a parancsolat Violaszín pecsét alatt. (Csokonai Vitéz Mihály) A Rigó sem az volt, aki tegnap estve, |  Hanem fekete, mint a fekete bogár, Elsikamlott szőrén a fényes napsugár. (Arany János) Este a kertben nézem az eget. (Kosztolányi Dezső) || a. A mai napnak ebben a szakaszában. Otthon leszel este? || b. (rendsz. határozott névelővel, múlt idejű igealakkal) A tegnapi napnak ebben a szakaszában. Mikor feküdtél le az este? Álmos vagyok, (az) este sokáig dolgoztam. □ Kissé hosszan elbeszélgettünk az este. (Gárdonyi Géza)
  • II. főnév estét, estéje [e, e-e]
  • 1. A sötétedéstől az éjszaka kezdetéig tartó napszak. Csillagos, sötét, téli este; → jó este; → öreg este; → sirató este. Leszállt az este: beesteledett, besötétedett. Este volt, mire hazaért; estére → kelve. Estére → hajlik az idő. Jó estét! (népies) Szerencsés jó estét! Jó estét kívánok! (népies) Adjon Isten jó estét!: <este találkozáskor, vhová belépéskor használt köszöntések, főleg idegenek v. baráti viszonyban levő ismerősök körében>. □ Este van, este van: kiki nyúgalomba. (Arany János) Már ránk szakadt a bús, vak este. (Ady Endre) Új rokon  | Biciklin járt, és ahol épp utól | érte az este, szállást kért s kapott. (Szabó Lőrinc)
  • 2. Esti rendezvény; est. Ismerkedő, műsoros este.
  • 3. Előeste. Sándor-nap estéje; (vallásügy) karácsony estéje: szenteste.
  • 4. (átvitt értelemben, költői) Az életnek végéhez közel eső, rendsz. hanyatló szakasza; hanyatló kor. Toldi estéje. □ Késő este van már életedben. (Petőfi Sándor) Olasznak süt a nap, annak áll a világ, Magyar! este van rád, neked jó éjszakát. (Arany János)
  • III. Ragos alakok és névutós kapcsolatok: estére; estéről maradt étel; estéről estére: (hosszabb időn át) minden este; estétől (fogva); (tegnap) este óta. Estére jár az idő: már-már este van. A maradékot elteszi estére. Este óta javult az állapota.
  • Szólás(ok): ld. tök.
  • Szóösszetétel(ek): előeste; karácsonyeste; szenteste.
